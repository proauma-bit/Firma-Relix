Cómo instalarla

Gmail / Google Workspace

  1. Pulsa Copiar firma completa.
  2. En Gmail: ícono de engranaje ⚙ → Ver toda la configuración → pestaña General → sección Firma.
  3. + Crear una nueva → nómbrala “Relix completa” → pega con Ctrl+V.
  4. Repite con la firma corta y nómbrala “Relix corta”.
  5. En Valores predeterminados de firma: mensajes nuevos → “Relix completa”; respuestas/reenvíos → “Relix corta”.
  6. Marca “Insertar la firma antes del texto citado…” y pulsa Guardar cambios al final de la página.

Outlook en la web / nuevo Outlook para Windows

  1. Engranaje ⚙ (arriba a la derecha) → Cuenta → Firmas.
  2. + Nueva firma → nombre “Relix completa” → pega con Ctrl+V → Guardar.
  3. Crea también “Relix corta”.
  4. En Seleccionar firmas predeterminadas: mensajes nuevos → “Relix completa”; respuestas o reenvíos → “Relix corta” → Guardar.

Outlook clásico de escritorio (Windows)

  1. Archivo → Opciones → Correo → Firmas…
  2. Nueva → “Relix completa” → pega en el cuadro de edición → Guardar. Repite con la corta.
  3. A la derecha, elige la firma para Mensajes nuevos y para Respuestas o reenvíos → Aceptar.

Celular

  1. Gmail app / Outlook app: usan su propia firma de texto. Ajustes → tu cuenta → Firma (o “Firma para móviles”) → pega el texto de la tarjeta 3.
  2. iPhone (Mail): Configuración → Apps → Mail → Firma → pega el texto.
Después de instalarla, envíate un correo de prueba a otra cuenta (por ejemplo, tu Gmail personal) y revisa que la fuente, los colores y los enlaces se mantengan.
